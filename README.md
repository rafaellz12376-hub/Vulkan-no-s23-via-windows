# Vulkan-no-s23-via-windows
Script Batch (Windows) para forçar a ativação do motor gráfico Vulkan (SkiaVK) na linha Samsung S23 via ADB.

# S23 Vulkan Tool

## Como usar
1. Baixe e instale o **Minimal ADB and Fastboot**.
2. Abra o Minimal ADB normalmente (**não** execute como administrador).
3. Com o celular conectado via Depuração USB, arraste o arquivo `vulkan.bat` para dentro do terminal e aperte Enter.
4. Escolha a opção numero 1 aguarde o celular ira reiniciar todos os apps.
5. Pronto, pode verificar com o GPUWatch ou qualquer outra forma e estara com vulkan.
